
# R-Data-Cleaning-Week-1

## Week 1: Data Cleaning and Preliminary Analysis using R

This project focuses on data cleaning, preprocessing, and preliminary analysis using R.

### Tasks Completed
- Dataset import and structure analysis
- Missing value detection and handling
- Outlier detection
- Data normalization
- Categorical variable encoding
- Descriptive statistics
- Correlation analysis
- Data visualization
- Creation of a cleaned dataset

### Tools Used
- R
- RStudio
- GitHub

### Dataset
Titanic dataset was used for this analysis.
